# OTAZU

Repositorios del equipo de tecnología de OTAZU: plataforma digital, datos y
seguridad.

Trabajamos con un marco propio de desarrollo seguro: ramas protegidas,
revisión de código obligatoria, escaneo de dependencias y secretos en el
pipeline, y entornos separados para desarrollo, staging y producción.

## Seguridad

Si has encontrado una vulnerabilidad en alguno de nuestros sistemas, **no abras
una issue pública**. Sigue el procedimiento de [SECURITY.md](https://github.com/Otazu-DTO/.github/blob/main/SECURITY.md).
