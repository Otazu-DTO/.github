# Política de seguridad

## Cómo reportar una vulnerabilidad

Si has encontrado una vulnerabilidad en un sistema, aplicación o repositorio de
OTAZU, escríbenos a **acaparros@otazu.com** indicando:

- Sistema o producto afectado y versión.
- Descripción de la vulnerabilidad y su impacto estimado.
- Pasos para reproducirla (sin usar datos reales ni causar daño).
- Evidencia: capturas, logs o vídeo **sin datos personales ni secretos**.
- Forma de contacto para el seguimiento.

No uses canales públicos —issues abiertos, redes sociales o pull requests— para
divulgar una vulnerabilidad sin corregir.

## Nuestros compromisos

- Acusar recibo en un plazo máximo de **2 días laborables**.
- Valorar y clasificar la vulnerabilidad por severidad.
- Mantenerte informado del estado durante el proceso.
- Corregir según los plazos internos de gestión de vulnerabilidades.
- Reconocer tu contribución, salvo que pidas anonimato.
- **Divulgación coordinada**: no hacemos pública la vulnerabilidad hasta que
  exista una corrección o mitigación, salvo acuerdo con quien la reporta.

## Alcance

Esta política cubre los sistemas y repositorios propiedad de OTAZU. Las
pruebas de seguridad deben hacerse de buena fe, sin comprometer la
disponibilidad ni acceder a datos de terceros.

## Alternativa privada en GitHub

En los repositorios que lo tengan activado, también puedes usar el reporte
privado de vulnerabilidades de GitHub (*Security* → *Report a vulnerability*).
